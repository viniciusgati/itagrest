# US006: Monitor de Preparo (KDS)

**Épico:** E2 - Gestão do Cardápio / Operação
**Status:** DRAFT (Novo)

## 📋 Descrição
Como cozinheiro, quero ver os itens pedidos pelas mesas em uma tela dedicada para que eu possa preparar os pratos na ordem correta.

## 🎯 Objetivo de UX (Simples & Rápido)
- **Cards de Pedido:** Cada mesa gera um card com a lista de itens e o tempo decorrido.
- **Ação Única:** Clique/Toque no item para marcar como "Em Preparo" (Laranja) e outro para "Pronto" (Verde).
- **Som de Alerta:** Um "beep" suave a cada novo pedido que entra.
